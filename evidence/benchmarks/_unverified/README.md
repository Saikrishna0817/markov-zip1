# Unverified evidence (quarantined)

These files were generated during an earlier development phase and were presented
as GPU performance evidence. An audit could not establish that they were produced
on real CUDA hardware with a trustworthy simplex baseline.

They are kept here for historical reference only. **Do not cite numbers from
these files in README, STATUS, CHANGELOG, or any public claim.**

Replacement artifacts must be produced by re-running the benchmarks on real
hardware after the simplex baseline is fixed (see remediation Phase 2 and 4).

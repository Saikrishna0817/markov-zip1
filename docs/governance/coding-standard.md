# C++ foundation standard

Use C++20, RAII, value semantics by default, explicit ownership, const-correctness, checked dimensions/arithmetic, no global mutable state, deterministic ordering, bounded allocations, warnings-as-errors, narrow CPU-neutral interfaces, and structured errors. CUDA types must never enter public CPU-neutral headers. Hot-loop allocation, exceptional constants, nondeterminism, and external process execution require explicit documentation and approval.

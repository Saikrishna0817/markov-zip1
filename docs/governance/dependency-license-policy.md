# Dependency and license policy — ADR-M0-04

Production distribution is Apache-2.0. New dependencies require identity, version, source, checksum, license, use scope, transitive inventory, security review, and an approval record. Copyleft or field-of-use restrictions require explicit legal/architectural approval. External solvers are never production dependencies and may run only as isolated benchmark oracles. M0 uses only the C++ and Python standard libraries plus CMake and host tools.
